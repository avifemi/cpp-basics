# Laboratory Work 1

Учебная работа по основам C++.

## Задание 2. Логические значения

В файле `task2.cpp` реализован класс `logical_values_array`, который хранит значение типа `unsigned int` и выполняет над ним логические операции.

При выполнении логических операций используется правило: `0` считается значением `false`, любое ненулевое значение — `true`.

### Реализованные методы

- получение хранимого значения;
- инверсия;
- конъюнкция;
- дизъюнкция;
- импликация и коимпликация;
- сложение по модулю 2;
- эквивалентность;
- стрелка Пирса и штрих Шеффера;
- сравнение двух чисел методом `equals()` (полная эквивалентность чисел);
- перевод числа в двоичную систему счисления;
- получение бита по позиции.

Методы логических операций изменяют значение текущего объекта и возвращают ссылку на него.

### Сборка и запуск

Для компиляции понадобится компилятор C++:

```bash
g++ -std=c++11 task2.cpp -o task2
```

Запуск в Linux и macOS:

```bash
./task2
```

В Windows:

```powershell
.\task2.exe
```
