# cpp-basics

Учебная работа по основам C++.

## Задание 1. Логические значения

В файле `logical_operations.cpp` реализован класс `logical_values_array`, который хранит значение типа `unsigned int` и выполняет над ним логические операции.

При выполнении логических операций используется правило: `0` считается значением `false`, любое ненулевое значение — `true`.

### Реализованные методы

- получение хранимого значения
- инверсия
- конъюнкция
- дизъюнкция
- импликация и коимпликация
- сложение по модулю 2
- эквивалентность
- стрелка Пирса и штрих Шеффера
- сравнение двух чисел методом `equals()` (полная эквивалентность чисел)
- перевод числа в двоичную систему счисления
- получение бита по позиции

Методы логических операций изменяют значение текущего объекта и возвращают ссылку на него.

### Используемые технологии

- C++
- Классы и объекты
- Конструкторы
- Перегрузка операторов
- Битовые операции
- Динамическое выделение памяти

## Задание 2. Комплексные числа

В файле `complex_numbers.cpp` реализован класс `complex_numbers` для работы с комплексными числами. Действительная и мнимая части числа хранятся в переменных типа `double`.

### Реализованные методы и операции

- конструкторы, включая конструктор копирования
- оператор присваивания
- сложение и вычитание комплексных чисел
- умножение и деление комплексных чисел
- оператор `+=`
- вычисление модуля комплексного числа
- вычисление аргумента комплексного числа
- вывод комплексного числа

Арифметические операторы `+`, `-`, `*` и `/` возвращают новый объект, не изменяя исходные числа. Оператор `+=` изменяет текущий объект.

При делении выполняется проверка знаменателя: деление на комплексный ноль обрабатывается как ошибка. Аргумент вычисляется с помощью `atan2()`, что позволяет корректно учитывать четверть комплексной плоскости. Для нулевого комплексного числа аргумент не определён.

### Используемые технологии

- C++
- Классы и объекты
- Конструкторы и конструктор копирования
- Перегрузка операторов
- Работа с комплексными числами
- Математическая библиотека `<cmath>`
- Обработка исключений
